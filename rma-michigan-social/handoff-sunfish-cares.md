This is a copy of the 4-slide SpringCreek carousel (section 392:12846). The layout, copy and photos are unchanged. Only the fonts, the colours and the partner logo changed.

## What changed

| Element | SpringCreek original | RMA version |
|---|---|---|
| Headlines, numbers, 01–05 | Flecha M Medium, olive #252900 | Lora SemiBold, navy #003887 |
| Body, list items, disclaimer | Inter Medium/Regular, olive/warm grey | Lora Regular: ink #1A1A2E, body #3A3A4A, grey #6E7482 |
| Pill labels | Inter Medium | DM Sans Medium |
| Backgrounds | Cream #FAF4EF / #FFF9F5 | White |
| Cards, disclaimer panel, URL pill | Peach #FFF3E6 / #FEF2E7 / #EEE7E1 | Mist #ECF1F8 |
| Cover pill | Near-black, orange arrow circle | Navy, white circle with navy arrow |
| URL pill arrow circle | Orange #F66504 | Navy |
| Petal textures (cover, slide 4) | Orange | Navy at 30% (alpha-masked recolour of the same art) |
| Ginkgo line art (slide 3) | Orange | Navy at 85% |
| Lockup | Sunfish Cares \| SpringCreek | Sunfish Cares \| RMA logo (navy) |
| URL | joinsunfish.com/springcreek | joinsunfish.com/rma |

Wider Lora metrics required two size changes:
- Slide 3 title: 70 → 64px. It now wraps to three lines.
- Slide 4 title: 92 → 84px, so "the new year?" clears the photo.

## Flags

1. **URL slug needs confirming with Sunfish.** `joinsunfish.com/rma` is a placeholder. The layer is named to say so.
2. **Offer terms need confirming for RMA.** The copy is kept verbatim: 26 patients, $26,000, $1,000, Dec 18, the Nov 16–Dec 18, 2026 window and the up to $15,000 refund.
3. **The blue brush texture on slide 2 is not recoloured.** It is baked into the campaign's friends photo file. It is periwinkle, not navy. Recolouring it needs the layered source file from Sunfish.
4. **No bottom-centre RMA logo on these slides.** The usual RMA rule puts the logo bottom centre on every slide. Here the original layouts already use the bottom of each slide (CTA pill, list item 05, disclaimer panel), so the RMA logo sits only in the cover lockup. A logo can be added if the layouts are allowed to move.
5. **The CTA pills are kept.** They are part of the client's layout. They are recoloured, not removed.
