# RMA of Michigan — social content (Innovation Fertility)

Everything for this project lives in this folder so it stays separate from the app code in the rest of the repo.

- `handoff-nov-1-14.md` — what was built for the November 1–14 batch, brand references used, and client flags
- `handoff-nov-15-28.md` — November 15–28 explorations: three on-brand versions of every post, plus client flags
- `handoff-community-grants.md` — Community and grants carousel from the graphic requests PDF: three options, plus client flags
- `handoff-trend-nov.md` — November trend slots (RMA): three posts in three versions each, plus client flags
- `handoff-veterans-day.md` — Veterans Day static (RMA): three versions, plus client flags
- `handoff-dec-batch.md` — December batch: status by week, three versions per asset, and client flags (weeks 5–6 built; weeks 7–9 next)
- `handoff-sunfish-cares.md` — Sunfish Cares holiday promo: SpringCreek carousel converted to RMA fonts and colours, with confirmation flags (URL slug, offer terms)
- `previews/` — contact sheets exported from the Figma Sandbox page
